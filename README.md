# キラキラ アイランド 🏝️

▶ **あそぶ： https://futsalife24-bot.github.io/Ichi-game/**

Ichi-game（娘用ゲーム）。もうすぐ4歳の子ども向けの **3D知育ゲーム** です。
島の上でキャラクターを動かし、どうぶつたちと遊びながら **いろ・かず・かたち・どうぶつ・ひらがな** にふれられます。
Three.js 製で、ビルド不要の静的サイト。PWA としてホーム画面に追加すると、オフラインでもフルスクリーン（横向き）で遊べます。

## あそびかた

1. タイトルで **うさぎ／ねこ／くま** をえらぶ（この操作で音と声が有効になります）
2. 画面上のカードに「おしごと」が出て、声でも読み上げられます（カードをタップするともう一度読み上げます）
3. こたえを見つけて **さわる** と ⭐ がもらえます
4. ⭐ 5・10・15・20 こで **ごほうび**（リボン → むぎわらぼうし → おはなのかんむり → おうかん）

### そうさ（横画面）

| そうさ | やりかた |
| --- | --- |
| あるく | 左下の スティック／画面を タップ・ゆびで おさえたまま なぞる（そこへ あるく） |
| ジャンプ | 右下の ピンクの ボタン |
| ぽよーん | 赤い きのこに のる |
| PC でテスト | 矢印キー／WASD、スペースでジャンプ |

### 知育の おしごと（順番にまわります）

| しゅるい | 内容 | 例 |
| --- | --- | --- |
| いろ | 指定の色のふうせんをさがす | 「あかい ふうせん を みつけてね！」 |
| かず | くだものを N こあつめる（1こごとに声で数え、数字も表示） | 「りんご を さんこ あつめてね！」 |
| かたち | まる・さんかく・しかく・ほし・ハート | 「ほし の かたち を さがしてね！」 |
| どうぶつ | 鳴き声からどうぶつを当てて会いにいく | 「もーもー って なく どうぶつ は だあれ？」 |
| もじ | ひらがなブロックをさがす（ことばと絵つき） | 「あひる の 「あ」 は どれかな？」 |

### かずの がっこう（きょうしつの すうじミニゲーム）

島の みどりの屋根に 時計台のある **がっこう** の前の **黄色く光るマット** にのると、教室に入れます（出るときは緑のマット）。ふくろう先生が 黒板で 問題を 出します。「じぶんの おうち」は 模様替え専用です。
黒板に問題が出て、床の **すうじマットに のる** か **タップ** してこたえます。3つのあそびが順番に出ます。

| あそび | 内容 |
| --- | --- |
| いくつ？ | 黒板の絵をかぞえて、同じすうじのマットをえらぶ。まちがえると、黒板の絵を1つずつ光らせながら「いち、に、さん…」と一緒にかぞえてくれる |
| じゅんばん | 部屋じゅうに置かれた 1〜5（6）のマットを、1から順番にふむ |
| おなじ かず | 黒板のすうじ（例：4）と同じ数の絵がのった「おさら」をえらぶ |

正解すると島と同じ ⭐ がもらえます（ごほうびも共通）。

- ⭐ が増えるとレベルアップ（色の数、数える数、ひらがなの範囲 あ行→か行→さ行 が広がります）
- まちがえても減点なし。「それは あお。あかい ふうせん は どこかな？」とやさしく教えてくれます
- 18 秒見つからないと **やじるし と 光の柱** でヒント
- にじの下をくぐると色の名前を読み上げ、ふくろう先生に近づくと今のおしごとを教えてくれます

## しまの くらし（どうぶつの森みたいな あそび）

おしごと とは べつに、島では いつでも「さわるだけ」で あそべます（道具は自動で持ちかえます）。

| あそび | やりかた |
| --- | --- |
| むし とり | ちょうちょ・てんとうむし・バッタ などに さわると あみで つかまえる（夜は ほたる、雨の日は かたつむり） |
| さかな つり | 浜辺で 水の中の さかなの かげに 近づくと つりざおで つる |
| かいがら ひろい | 浜辺で キラッと光る かいがら・かに・ボトルメール を ひろう |
| かせき ほり | 地面の「×」じるし に のると スコップで ほる（きょうりゅうの かせき・ベルぶくろ など） |
| 木を ゆらす | 木に ぶつかると ゆれて、くだもの・どんぐり・ベル・⭐・プレゼント が おちてくる |
| はたけ | 「はたけ」の 土に のると たねを うえる → のると 水やり → 数分で さく → のると つむ |
| おみせ | 「たぬきの おみせ」で ベルを つかって たね・かぐ・ふく を かう。青い「うる」ばこ に さわると もちものを ぜんぶ ベルに かえる |
| ずかん 📖 | つかまえた もの・ひろった もの が のる（34しゅるい）。カードを タップすると 名前を よみあげる |
| きせかえ 👕 | ぼうし・めがね・ふく を えらぶ（⭐の ごほうび ＋ おみせで かった もの） |
| じぶんの おうち | 青い屋根の おうち。下の トレイで かぐを えらんで 床を タップ → おく。おいた かぐを タップ → まわす（「しまう」で もどす）。かべを タップ → かべがみ が かわる。ピアノ・ランプ・テレビ は さわると うごく |

- **じかん**：端末の時計に あわせて 朝・昼・夕方・夜 で 空・光・BGM が かわる（夜は 街灯と 窓に あかり、星と 月）
- **きせつ**：月に あわせて 木の色が かわる（はる＝さくら／なつ＝みどり／あき＝こうよう／ふゆ＝ゆき）。お店の かぐ や でてくる むし も かわる
- **てんき**：ときどき 雨（ふゆは 雪）。雨の日は はたけが 早く そだつ。やむと にじが キラキラ
- どうぶつ や たぬきさん が しゃべると、名前つきの ふきだし と「ぽこぽこ」どうぶつ語が でます
- ためしたい とき：URL に `?hour=20`（時刻）・`?month=12`（月）・`?weather=rain`（雨）を つけると 切りかえられます

## おと

- **BGM**：Web Audio API でその場で演奏するオリジナル曲（音源ファイルなし）。朝・昼・夕方・夜で 曲が かわる
- **効果音**：ジャンプ・きのこ・正解・かぞえる音（ドレミ）・ファンファーレなど、すべて合成
- **声**：事前に作った音声ファイル（`voice/*.mp3`、Open JTalk ＋ HTS Voice “Mei”）を再生。字幕も表示
  - 端末の読み上げ機能に頼らないので、日本語の読み上げがない端末（Fire タブレットなど）やオフラインでも喋ります
  - 音声ファイルがないセリフのときだけ、端末の読み上げ（Web Speech API）を使います
- 右上 🎵 で BGM、🗣️ で声を ON/OFF、🏠 でキャラ選択へ

> 声が出ないときは、まず端末の音量・マナーモードを確認してください。

## 公開（GitHub Pages）

1. このブランチを `main` にマージ
2. GitHub の **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする
3. `main` に push すると `.github/workflows/pages.yml` が `https://<ユーザー名>.github.io/Ichi-game/` に公開
4. タブレット／スマホでそのURLを開き「ホーム画面に追加」→ アプリとして起動

## ローカルで動かす

```sh
npx http-server -p 8080 -c-1 .
# → http://localhost:8080
```

（ES Modules と Service Worker を使うので `file://` ではなく HTTP サーバー経由で開いてください）

src/quests.js      知育クエストの進行・ヒント・ごほうび
src/school.js      がっこうの教室と すうじミニゲーム

src/catalog.js     ずかんに のる もの の リスト（ねだん・でる きせつ／じかん）
src/furniture.js   かぐ の モデル と ねだん

3D モデルはすべて Three.js のコードで作っているので、Blender なしで色や形をかえられます。
将来 Blender で作ったモデルを使いたくなったら、glTF（.glb）で書き出して `GLTFLoader` で読み込めます。

### セリフ（声）を変える・増やす

セリフはすべて `src/lines.js` にあります。変更したら音声ファイルを作り直してください（文ごとの mp3 を作り、使わなくなったファイルは消します）。

```sh
sudo apt-get install open-jtalk open-jtalk-mecab-naist-jdic lame
# MMDAgent_Example（https://sourceforge.net/projects/mmdagent/）の Voice/mei/mei_happy.htsvoice を用意
MEI_VOICE=/path/to/mei_happy.htsvoice node --import ./tools/register.mjs tools/gen-voice.mjs
```

### カスタマイズのヒント

- 進行度をリセット：ブラウザのサイトデータを消去（`localStorage` の `kirakira-island-save-v1`）
- 新しいことばを追加：`src/props.js` の `MOJI`（追加したら音声ファイルも作り直す）
- 曲を変える：`src/audio.js` の `MELODY` / `CHORDS`
- ファイルを更新したら `sw.js` の `VERSION` を上げると、インストール済みアプリにも確実に反映されます
