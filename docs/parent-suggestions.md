# 保護者向けの難しさ提案

2026-10-03。ブランチ codex/parent-suggestions、基点 5b7eccfe4fc12e87171b981b4b9b720e2d62e62e。ユーザーが「保護者に提案し、採用した時だけ変更する」を選択。任意の独立監査なし、主担当の自己検証で進めた。

## 画面と動作

タイトルの「記録を見る・保存」→「いまの子の遊びの設定」に提案表を追加。色・形・ひらがなごとに観察状況と根拠を表示する。提案ボタンを押すと設定欄が変わり、「保存する」で初めて確定する。保存せず戻ればゲーム設定は変わらない。難しさとヒントはいつでも手動で選べる。

| 状態 | 表示と操作 |
| --- | --- |
| 従来の星連動 | 固定設定を選ぶと、その設定で観察を始める案内 |
| 新規記録が不足 | 同じ設定で完了した活動の件数 |
| 支援あり・複数接触・目標の偏り | 今の設定を続ける候補。自動で下げない |
| 試作条件を満たした | 根拠と、一段階上を試すボタン |
| 最後の設定 | 現在用意している最後の設定と表示。能力ランクとは呼ばない |

## 試作条件と限界

固定設定で直近8回の完了がすべてゲーム内ヒントなし・対象への接触1回、目標が3種類以上なら、一段階上を提案する。8回・3種類はゲーム用の暫定条件で、発達基準や効果が検証された数値ではない。画面にも明記する。反応時間・年齢・遊ばない期間・中断・聞き直しで難化／易化しない。

保護者の声かけや偶然の到達は分からない。実プレイの負担と比べて条件を見直す。学校・お手伝い・数集め・鳴き声は難化の提案から除外する。数集めは全果物が正解なので、収集完了を数の理解と認定しない。

配置場所の不足で候補数が減った活動も難化提案の条件に含めない。設定ごとに意図した候補数がそろっていることを確認する。

自動ヒントは従来18秒。ヒントの記録がある時は難化を提案しないが、苦手・失敗とは扱わない。保存するのは開始時の自動／手動設定とヒント回数。個々のヒントの提示経路や支援段階までは区別しない。

## 保存・既存セーブの保護

子どもの game.suggestions に任意項目 version:1、recent、after を追加。recent は色・形・ひらがな各8件まで。活動ID、出題版、実質の段階、目標ID、実際の候補数、ヒント設定、接触・ヒント・聞き直し回数を保持する。名前・出生年月・絶対日時・外部送信は追加しない。

旧セーブは提案用履歴なし。累計や直近2回から履歴を捏造しない。完了・星と同じ保存で根拠を確定し、失敗時には追加記録・完了・星を戻して後続保存を停止する。重複完了は活動IDで無視する。

after は設定変更時点の活動ID。難しさかヒント設定を変えたら、途中だった活動も含め、変更時点以前の根拠で提案しない。異なる段階・ヒント設定を挟んだ完了も混ぜない。保留履歴は保存せず、通知やポップアップは出さない。設定画面を開き直すと、根拠が同じなら同じ候補を表示する。

旧記録・持ち物・旧保存キーは削除しない。既存のプロフィール全体の書出し・控え・復旧に追加項目も含まれる。更新前の書出しで復帰点を確保できる。破損・将来版・活動IDの矛盾は初期化せず停止する。
