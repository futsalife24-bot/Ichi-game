# 第四〜第八島の実画面確認の現在地

2026-10-13、隔離された開発者モードの専用Chromeタブ `1271484106` で `http://127.0.0.1:5225/?dev=workshop` を開き、通常の開始ボタンを押した。通常プロフィールには触れていない。IABは利用不可だったため、主担当と調整してChrome専用タブを使用した。

第四島の実スクリーンショットでは「だいよんの しま・ものづくりの しま」と表示され、中央木道、作業面、掲示板、かご、家の積み木、左右のお題場所を目視した。中央道は奥まで見える。開始直後のAX木には第一島と出たが、遷移後の再取得では第四島へ更新され、持続する不一致ではなかった。ゲーム内のエラー画面は見えなかった。

ジョイスティックを約２秒押す操作はコンピューター操作の接続がタイムアウトし、入力の成立を確認できなかった。再接続時はブラウザー一覧が一時空になり、その後タブの一覧は復帰したが、専用タブへの再接続は `Debugger unattached` となった。重複入力を避けて操作を停止した。第五・第八島、667×375と844×390、歩行、家具の接地、各島の問題・おてつだい、誤答からの復帰は実画面未確認。開発者モードの隔離データのため、通常の保存を削除・変更していない。

素材の単独Blenderレンダーは [原本と報告](../assets-src/islands/learning-kit-geometry-report.json) と front/side/top および島別拡大PNGで確認したが、実景観での見え方の代わりにはしない。実画面確認の続きはコンピューター操作の接続が安定した後、専用タブと隔離モードから再開する。

この第四島の表示確認は素材の細部を仕上げる前の版。最終版の全５島は未確認で、第六島の海底ドーム・魚とサンゴ、第七島の浮島・雲・橋も実画面確認の対象へ加える。通常保存の削除は必要ない。最新の一覧では専用ゲームタブが `1271484142`、音声制作タブが `1271484139` へ変わっている。主担当の接続再確認でもタブ取得がタイムアウトし、台本入力や追加生成は行えなかった。画面の不明な操作を重ねず、Chrome拡張の再接続を本人へ依頼済み。
