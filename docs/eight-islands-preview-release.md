# 八島の先行公開と音声収録の継続

2026-10-13。本人の「チェックするから公開して。ボイスは引き続き生成を進めて」に従い、追加録音が揃う前に本人確認用の八島を公開する。基点は `8479f9b1b931c90517384e207dac0ae04d08a8eb`、作業ブランチは `codex/island-learning-balance`。実装の基点、素材と学習の内容、実施済み検査は [実装記録](eight-islands-implementation.md) を参照する。

## 公開の条件

既存の726音声は全MP3・出荷一覧・取り込み記録・通常収録対象の対応を検査する。今回の85未収録分だけを `assets-src/gemini-tts/release-allowlist.json` で明示し、計画、言語、台本、固定した既存一覧・記録を照合する。未収録分を消したり成功済みに置き換えたりしない。追加計画、キャッシュ、保存、景観など既存の必須検査は引き続き実行する。

`tools/finalize-voice.mjs --check` は全収録完了の検査として残す。公開用の `--check-release` は今回の先行公開条件を検査し、未収録が増えたり既存音声が失われたりした時に拒否する。録音後は全件完了を検査して通常の出荷一覧へ統合し、暫定の許可一覧を終了する。

## 画面と音声

Chrome拡張の操作接続は再確認でもタイムアウト。アプリ内ブラウザーでAI Studioと確認用ゲームの表示は取得できたが、ボタン操作の結果が画面へ反映されない。AI Studioは既存のGemini 3.8 Flash TTSを表示し、未入力の作成画面。今回も追加録音はまだ生成していない。本人へChrome再接続を依頼済みで、接続復旧後にバッチ31〜39を順に生成・取り込み・照合する。

本人が公開版で確認する方針を受領した。最新版の全島の歩行、問題・おてつだい、小型画面は主担当の実操作未確認として記録し、表示取得や自動テストを実プレイ成功とは扱わない。追加録音がない箇所は既存の端末読み上げへ進み、英語の端末音声がない環境では日本語で代用しない。
