# 八島の景観制作goalの仕上げと公開

2026-10-14。本人採用の[原画８枚](../assets-src/islands/concept-art/v1/README.md)と[制作基準](../assets-src/islands/concept-art/v1/PRODUCTION.md)を正本に、八島の地形・主役・建築・植生・光・遠景・歩行路を作り込んだ。本人の「自己検証で公開して」「goalまでやって」に従い、追加の独立監査を挟まず主担当が統合と自己検証を担当した。仕上げ版をmainへ公開し、公開版の全８島の到着・通常操作・大きい横画面と小さい横画面の確認まで完了した。景観goalを完了とする。

## 自己検証と原本の保存

[検証記録](concept-goal-check.json)と[原本の点検](concept-goal-native-inventory.json)を参照。両公開ワークフローの49テストファイルと必要な資材検査を実行し、328テスト成功。最終の川・きのこ・水面・確認地点・切り紙の調整後には、歩行・カメラ・世界・祭り細部・SWの33テストも成功した。その後、最終の公開mainでも全328テストが成功した。後続の確認を足してテスト総数を水増ししていない。

最初の全体検査では、祝い席の支柱が既存の学習入口と重なり、景観の３部品が旧学習キットの台帳へ混在して４件失敗した。天幕を回して入口を空け、景観部品は景観正本へ保持して混在を解消。関連24件が成功。その後、川筋変更でジャンプきのこ２か所が水に入ることを世界検査で検出し、陸へ移して33件を成功させた。検査・Hooks・CIを省略していない。

PCの確認用WebGLで、実際のPlayerを1/60秒刻みで動かし、各島の入口・主役前・脇道と、第二の渡河・第八の祝い席への合計18経路を確認。到着の画面表示と位置・歩数を記録し、[歩行画像10枚](concept-goal-proof/)も保存した。撮影位置へ移すボタンによる移動は歩行記録へ含めない。これは通常UIの操作や端末の実速度の検査とは分けている。ブラウザーの警告・エラーは０件。

景観模型はA13点・B17点・自然10点の計40点。編集原本の実ファイルは、Aの合同２本・Bの個別17本・自然の個別10本の計29本。各模型の生成元・原本・見本・寸法報告・配信形状は全件一致。コードで組む地形・道・水・雲・植生の原本もリポジトリに保存。学習用素材76点・新規学習キット34点は保持し、新しい祝い席３点は景観台帳に記録した。
