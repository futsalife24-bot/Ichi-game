# 第二島をレンガと水路の港町へ作り直す

記録日：2026-10-08。制作・自己レビュー・実ゲーム確認を完了。**未公開**。独立監査の実施可否は本人の返答待ち。

## 依頼と完成条件

本人から、第一島に対して第二島の景観・遊べる範囲・木の造形が見劣りし、色も似ていて新しい島に来た感覚がないとの指摘を受けた。収集する葉が既定の絵文字で、手前の木を透過して見える描画も問題になっていた。

今回は第二島を、赤レンガの建物、クリーム色の石畳、青緑の屋根と水路、珊瑚色・琥珀色の街路樹がある港町へ変更する。到着時の一画面に独自の建物と遠景が見え、道を歩いて建物・水車・海岸へ寄り道できることを重視する。第三・第四島は今回の実装範囲に含めず、島ごとの色・主景・歩く遊びを変える方針を資料に残した。

## 実装した景観と遊び

### 六棟の港町と石畳

到着側のレンガ住宅、パン屋、時計塔、小さな住宅に、島の奥の温室、水路沿いの水車小屋を加えた六棟で構成する。建物は窓・扉・屋根・看板・入口が通常カメラでも読める大きさで置き、それぞれの入口へ舗装された道をつなぐ。建物の外観と入口周辺を整える改修であり、新しい入店機能は追加していない。

レンガは目地をあけて積み、屋根の瓦、窓の石枠、アーチ入口、パン屋の縞庇と立体パン看板、四面の時計盤と針、温室の格子と植木鉢を造形した。街路には灯籠、旗、噴水、岸壁を置き、暖色の建物と青緑の水が対比する場所にした。

舗装は地形の起伏に追従する厚みのある石として描く。建物の基礎と入口周辺は地面につなぎ、見える玄関段・噴水・植木鉢にも移動上の当たり判定を設ける。

### 水路・水車・生き物

既存の小山の泉、上流、滝、川のつながりを引き継ぎ、街に流れる水路の護岸と橋を組み合わせた。水車は単体で置かず、小屋の壁まで車軸を接続し、流れを使う建物として見えるようにした。

水面には川の曲がり方と水位に従う短い水筋と紙船を追加。港を巡るカモメ、花壇の蝶、収集した場所で短く散る立体の光片も加えた。NANKA DEKIRUの公開見本から動きの発想を参考にし、本作の三次元の川・地形・深度に合わせて独自実装している。

### 立体の葉と、枝が見える街路樹

収集する葉を、緑・琥珀・赤の三色の立体素材へ置き換えた。茎、葉脈、折り目、厚み、表裏を持ち、地面には接地影を残す。通常の深度検査と深度書込みを有効にし、手前の木や建物が葉を遮る前後関係を保つ。

樹木は大きい球の樹冠から、曲がった幹・根・分岐した枝・個別の葉が見える街路樹へ変更。樹冠を狭くし、枝の間に空間を残した。主人公とカメラの間にある建物や木については、主人公の周囲だけを局所的に見通せるようにする。葉や主人公を常に最前面へ描く処理ではない。

第二島専用のカメラ位置と注視点を調整し、足元だけでなく時計塔・水路・奥の建物へ視線が続く画角にした。

### 海岸・釣り・貝拾い

海岸の境界を見える地形に合わせて広げ、海沿いの道と四つの寄り道先をつないだ。川の河口や危険な側から建物へ押し出される問題を避けながら、水際近くを歩けるようにする。

第二島の海に三か所の釣り場を設け、既存のアジ・クマノミ・フグを釣れるようにした。砂浜には巻貝とホタテを配置。釣りには竿・糸・浮き・引き上げ、貝拾いにはその場所での反応を付け、入手品は既存の所持品・図鑑へ渡す。ゲーム画面やパネルを離れた場合は進行中の釣りを解除する。

## 保持する進行と音声

既存の第二島の識別子、葉を集めて届ける進行、報酬、帰島、通常プロフィールと開発者確認用状態の区別を維持する。所持品・図鑑は既存の入手処理を使用し、保存形式の移行を追加しない。

音声は既存の708個を継続して使い、新規生成や差替えは行っていない。`finalize-voice.mjs --check` で708個の完全性を確認。保存を使う実Playerの一周、入手品と図鑑、通常プロフィールから独立する確認用状態の回帰テストも成功した。

## 分担と検証の区別

主担当と三担当で編集範囲を分けた。正式な独立監査とは別の、制作工程と統合検証の分担である。

| 担当 | 主な範囲 |
| --- | --- |
| 主担当 | 港町全体の構図、建物と素材の統合、水路と小物、深度と主人公の視認性、カメラ、実ゲーム画面・進行・公開条件の最終確認。 |
| Blender担当 | 建築・時計・樹木・収集葉・街灯の10素材、原本・ゲーム形式への書出し、レンダー、素材検査と制作手順。 |

| 地形・経路担当 | 海岸の移動範囲、建物周辺の地形と経路、水車小屋の配置・接続・実Playerの移動検証。 |
