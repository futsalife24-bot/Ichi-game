# 子ども別の誕生日のお祝い

2026-10-04。基点は公開main `9fcbfb420139df7e1f9e7131547f27bf208d732c`、ブランチ `codex/birthday-celebration`。ユーザーが「進めて」と回答し、下記の扱いを承認した。

## 動作

| 項目 | 採用した扱い |
| --- | --- |
| 登録 | タイトル右下「おうちの方へ」→「いまの子のお誕生日」。出生年・月のみ任意登録。未登録でも遊べる |
| 最初の対象 | 登録した月以降に迎える誕生月。当月登録を含む |
| お祝い時期 | 誕生月の翌月以降、最初に遊びを開始した時。12月生まれは翌年1月 |
| 長期休止 | 未実施分が複数年あっても最新1回だけ |
| 訂正 | 始めたお祝い・実施済みのお祝いは訂正で繰り返さない |
| 内容 | 絵と短いメッセージ、「あそびに いこう」。難しさ・星・持ち物・鍵は変更しない |

出生年は入力の確認と、生まれた直後を1歳の誕生日として祝わないために使う。年齢による初期難易度や自動難化は今回の対象外。西暦1900〜9999は入力上の技術的範囲で、ゲームの対象年齢を意味しない。

お祝いはプレイ時間の計測開始前に表示する。閉じてから時間設定・お手伝いへ進む。期限画面・お手伝い画面と重ねない。音声なしでも絵と文で分かる構成とし、新規音声生成・名前音声の公開は行わない。

## 保存と訂正

子どもの game.birthday に任意項目 version:1、birth（出生年・月）、registered（登録年・月）、lastYear（処理済みの誕生日年）、pendingYear（表示待ちの誕生日年）を置く。日にち、本名、絶対時刻は追加せず、外部送信しない。既存セーブは登録なしとして読む。

判定は端末の現地年月。表示した年ではなく「どの年の誕生日か」を記録する。開始の保存が成功してから画面を表示し、閉じる保存が成功してからゲームへ進む。表示中の再読み込みは同じ回を再開。連打で再度完了しない。表示途中のまま数年休止した時も、最新分にまとめる。

出生年月の訂正では元の登録月を維持する。ただし訂正後の出生年月が元の登録月より後なら、今回の訂正月を登録月にする。表示待ちのお祝いがある状態で訂正・解除した場合、その年は処理済みとして保持する。変更なしで保存した場合は表示待ちを維持する。

登録解除は確認文を表示し、現在の出生年月と登録年月を外す。重複防止の処理済み年は残す。過去の控え・書出しに残る出生年月をすべて消す操作ではないことを画面に明記する。再登録した場合はその月から対象にする。

時計を過去へ戻しても処理済み年は戻さない。未来に誤設定した端末で完了すると、その年以前のお祝いは繰り返さない。端末だけでは正しい現在年月を保証できないため、保護者画面に時計設定の確認を案内する。外部時計サービスは使わない。

## 既存データの保護

既存のプロフィールストア・全体書出し・控え・復旧に含める。保存失敗時は直前の誕生日状態へ戻し、同じ画面から後続保存・ゲーム開始をしない。保存エラー画面を最前面にし、設定画面・お祝い画面は隠す。不正形式・将来版・対象外の表示待ちは初期化せず拒否する。既存キー・持ち物・活動記録を削除しない。

復旧には既存の「記録を見る・保存」の書出しと控えを使用する。公開前の書出しで復帰点を確保できる。プロフィール全体の復旧なので、他の子の状態も含めて確認して操作する。
