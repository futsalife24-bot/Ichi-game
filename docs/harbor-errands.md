## 港町ならではのおつかい

| 仕事 | 遊び | 配達先 |
|---|---|---|
| こむぎを はこぼう | 穂の多い袋を見比べる | 水車小屋からパン屋 |
| パンを そろえよう | 置いてあるパンに足して指定数にする | パン屋から時計広場 |
| おはなの つづき | 色と形の並びの続きを選ぶ | 温室から時計広場 |

受注・移動・問題・持ち運び・配達をつなぎ、途中保存する。間違いは減点せず、ヒントと聞き直しを使える。３件は別々に再開できる。配達済みのパンや花が街に残り、３件そろうとおやつ会の準備完了を表示する。各仕事の初配達だけ星１個。再挑戦では少しずつ問題が変わり、星は重複付与しない。葉のお手伝い・釣り・帰島も保持。

問題の絵は専用SVG。持ち運ぶ袋・パン・花はThree.jsの立体。パンは問題の５〜８個と手持ち・広場の実物数を一致させた。既存の港町の景観素材は維持。

## 第一島の自動調整

対象は第一島の「みつける あそび」。色・形・数・ひらがなを別々に調整し、星や港町の報酬は使わない。固定設定を優先し、開始時の設定を活動終了まで保持する。旧記録から成績を推測せず、自動は設定１から新しい記録をためる。

- 同じ設定の８完了で、すべてヒントなしの場合に一段階先を検討する。
- 色・形・ひらがなは目標３種類以上、各回接触１回、実際の選択肢数がそろった時だけ上げる。
- 数は必要数２種類以上、必要な個数だけ集めた時だけ上げる。すべて正解の収集物なので、接触数を誤答と扱わず、自動では下げない。
- 色・形・ひらがなは直近４完了のうち３回以上、違う対象へ２回以上接触した場合に一段階戻す。
- ヒント・聞き直し・遅さ・中断だけでは下げない。調整後と設定変更後は、新しい窓で確認する。

保護者画面には自動／固定と現在の設定を表示する。動物の鳴き声には段階差がないため調整しない。学校は従来の別の出題体系（星連動）のまま、港町のおつかいは各仕事の再挑戦回数で変化する。この試作条件は能力や発達の判定ではない。

## 次の島への案内

「みつける あそび」３完了後、安全な区切りに花のお手伝いを一度案内。花の配送後は「ふねで あそびにいく／このしまに いる」を直接選べる。既存の花完了データにも未訪問なら一度案内する。船の解放条件は花の配送完了のまま。断っても冒険メニューから再開可能。

活動・報酬・休憩・屋内・釣り・遷移・音声準備と字幕の間は割り込まない。案内履歴と初訪問を保存し、繰り返しを抑止。保存失敗時は表示・移動・報酬を進めず、追加状態を元に戻す。

本人承認の独立監査を実施し、以下を修正・再監査した。修正必須の残件なし。

1. パンの実物が問題数より少ない → 手持ち・配達先とも指定数へ。
2. 再挑戦の紹介に前の問題数が出る → 次回の問題を先に表示。
3. 活動記録に自動調整未実装の説明が残る → 現行の説明へ。
4. 音声の準備中に船案内が割り込む → 一覧・デコード・動物の声の待機と字幕も待つ。

自己確認では小画面の開発ボタンと問題操作部の重なりも解消した。独立担当による40活動の混在確認でも、固定優先・分野別調整・保存検査が整合した。
