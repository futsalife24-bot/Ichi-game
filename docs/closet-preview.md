# 着せ替え中のキャラ拡大表示

## 対象と変更

2026-10-05、ユーザーのスマホ画像と「着せ替える時はキャラを画面左にアップにして表示」の指示に対応した。ブランチは `codex/closet-preview`、基点は公開記録の `b1bcdc2acbc7fbd7fdde3fde308198001d4dfa9c`。公開mainは `08f9adf204ab64c1feff1892e862a65505cf617a`。

従来は遠い島の視点を維持したまま、右側に衣装一覧を重ねていた。着せ替え中だけ、左側に明るい背景で正面のキャラを拡大表示する。頭から足までが収まり、帽子・めがね・服と「なし」の選択が即座に反映される。島でのキャラの位置・向きは変更せず、閉じると通常の画面に戻す。

## 実装

- `src/closet-preview.js`：現在の衣装を含むキャラの表示モデルを複製し、左枠に正面から描画。道具と頭上の絵文字は除外し、形と色の共有データを破棄しない。キャラと衣装の外形から倍率を決め、耳や帽子・足を見切れさせない。既存の描画器を使い、WebGLの描画器を追加しない。
- `src/main.js`：着せ替えの開閉と衣装の選び直しに接続。閉じる時の描画領域と操作の復帰を維持し、図鑑には適用しない。
- `index.html`・`style.css`：左の表示枠と説明用のラベルを追加。着せ替え中は島のボタン・字幕を隠す。
- `sw.js`：`kirakira-v24-closet-preview` と新しいモジュールのキャッシュ登録。音声・保存形式・衣装の入手条件は変更していない。
- `tools/closet-preview.test.mjs`・CI：位置と共有データの保護、全衣装の収まり、更新と閉じた後の片付け、描画失敗時の通常領域への復帰を4件追加。
- `.gitignore`：利用者が添付した画像のフォルダを除外。元画像は保持し、GitHubへ送信しない。
