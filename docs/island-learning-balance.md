# 第一島から第三島までの知育と遊びの配分

2026-10-12。本人の依頼は「第一島を最もやさしい島として、既存機能を最低限の知育へ絞る」「第二島・第三島へ段階的に機能を追加する」「第二島からアルファベットか英単語の学習を始める」。この文書は今回の配分の正本。実装範囲への回答前に整理した設計で、下記を実装済みとは扱わない。

## ねらいと難しさ

第一島は、文字を読めなくても、声・絵・タップや短い移動で遊べる入口にする。第二島は見本合わせと一つのお届け、第三島は比較・規則性・数の補充・複数手順へ広げる。島を進めても、第一島の問題は難しくしない。

既存文書には「もうすぐ４歳向け」とあるが、３島の推奨年齢は定義されていない。そのため具体的な年齢は今回の確定仕様に追加せず、第一島が最もやさしいという順序を採用する。出生年月、星の数、正解率で入島を制限しない。推奨年齢を後から定めても、遊べる条件とは分ける。

第一島の中心は色・形・数・どうぶつの４分野だけ。施設や管理画面を減らし、同時に複数のお願いを出さない。お手伝いを終えなくても、基本の知育を繰り返せる。第一島のお手伝いの数も最大３に収める。

第二島は、第二島の新しい遊びを一度に全部提示せず、見本合わせ、文字、収集の入口を分ける。第三島は、第二島で触れた内容を暮らしやおつかいに使う場所にする。３島の学習内容は累積で、前の島へ戻って復習できる。

## 英語の最初の体験

第二島では、見本の大文字と同じカードを選ぶ。最初は少数の文字を繰り返し、全２６文字を一度に出さない。絵を添えて、文字と身近なものを結び付けることはできるが、つづりの暗記や入力は求めない。

第三島では、果物・どうぶつ・色など、既存の絵を使える少数の英単語から始める。絵を見て単語を選ぶ問題と、単語を聞いて絵を選ぶ問題は別々に出し、初めから複数の条件を組み合わせない。誤答では減点せず、正しい絵・文字を示して再挑戦できる。

英語の発音は日本語音声で代用しない。録音または端末の英語音声を使い、音声のない環境でも見本合わせは遊べるようにする。聞き取りだけの問題は英語音声の利用を確認できた場合に限る。追加録音は未生成で、既存の音声一覧・原本・未収録計画を保護する。費用の発生や外部生成サービスへの送信は既存の承認境界に従う。

## 今ある機能の扱い

現状の第一島は、５分野のみつける遊び、数字の学校、虫・魚・貝・化石の収集、木ゆらし、畑、店、売却、図鑑、家具の配置を持つ。第二島の実装は `Forest` を入口にする港町で、森のお届けと港町のおつかいが同じ第二島に属する。第三島の独立した場所・船・復帰処理はまだない。

後続島へ移す対象はコードやセーブを削除せず、施設・画面・出題する場所を変更する。港町を第三島として分ける場合、第二島の森を復元する作業と、港町の名前・帰路・案内の対応が必要である。名前だけを第三島へ変えて、同じ島の移動と呼び替えない。

星で難しさが変わる学校と、分野別の自動調整があるみつける遊びは別体系になっている。第一島には島ごとの上限を適用し、高い固定設定や既存の星があっても基本範囲を超えない。設定を消さず、後続島で使えるようにする。島ごとの問題を既存の調整記録へ追加する際は、問題条件が異なる記録を同じ成績として扱わない。

## 実装の順番と合格条件

1. 島別の出題範囲と利用できる機能を１か所に定義し、第一島の問題・施設・画面の入口に適用する。
2. 第二島にひらがな・大文字・１〜５の数の遊びと収集を追加する。
3. 第三島の独立した場面・移動・帰還を作り、港町のおつかいと暮らしの機能、身近な英単語を配置する。
4. 保存・中断再開・別プロフィール・音声・画面の確認を行い、対象版と証拠を記録する。

| 確認対象 | 合格条件・確認方法 |
| --- | --- |
| 第一島 | 新規・星が多い旧セーブ・高い手動設定でも４分野の基本範囲だけ。ひらがな、学校、店、畑、家具の入口が出ない |
| 第二島 | 大文字の見本合わせが実際に選択・再挑戦でき、英語音声がなくても進行可能。基本知育とひらがなも遊べる |
| 第三島 | 独立した移動先として往復でき、英単語・比較・規則・補充・暮らしの入口が使える |
