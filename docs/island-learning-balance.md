# 第一島から第三島までの知育と遊びの配分

2026-10-12。本人の依頼は「第一島を最もやさしい島として、既存機能を最低限の知育へ絞る」「第二島・第三島へ段階的に機能を追加する」「第二島からアルファベットか英単語の学習を始める」。続けて、実装まで進めること、第一島の数を１〜１０へ広げること、見える虫・魚・地面の収集物を第一島に残し、木ゆらしやジャンプによる収集は第二島以降とする指示を受領。この文書は今回の実装と配分の正本。

## 国の幼児教育資料との照合

実装時は本人の観察と指示を基準に配分しており、国の要領を明示的に参照して設計したものではない。2026-10-12の本人の質問を受け、公開前に[文部科学省の幼稚園教育要領（平成29年告示）](https://www.mext.go.jp/component/a_menu/education/micro_detail/__icsFiles/afieldfile/2019/09/19/1384661_3_2.pdf)の第１章第１・第４と第２章、[こども家庭庁掲載の保育所保育指針解説](https://www.cfa.go.jp/sites/default/files/node/basic_page/field_ref_resources/e4b817c9-5282-4ccc-b0d5-ce15d7b5018c/36b55701/20231016_policies_hoiku_66.pdf)の数量・図形・文字の説明（本文92・254ページ）を照合した。

要領は健康・人間関係・環境・言葉・表現の５領域を、主体的な遊びと一人一人の発達に応じた関わりを通して総合的に扱う。数・文字は生活や遊びの必要感から親しみ、正確な知識の習得だけを目的にしない。本ゲームでは第一島の実物の１〜１０、色・形の発見、動植物の収集を興味への入口、第二島以降の見本合わせ・比較・お届け・模様替えを試行錯誤の機会として対応付ける。この対応は制作側の判断であり、教育効果の実証や要領への全面準拠・国の認定を意味しない。

国が「３歳で１〜１０」「４歳で英語」と定めているわけではなく、島の順序と問題範囲は本人の希望によるゲーム内の配分。英語は要領の必修教科として扱わず、第二島から任意で触れる追加の遊びとする。正答率・暗記・文字の読解を次の島への条件にしない。実際の自然体験・運動・人とのやり取りをゲームだけで置き換えず、保護者と発見を話すなど日常の遊びへつながる補助として位置付ける。今回の照合で新たな機能や年齢制限は追加していない。

## ねらいと難しさ

第一島は、文字を読めなくても、声・絵・タップや短い移動で遊べる入口にする。第二島は見本合わせと一つのお届け、第三島は比較・規則性・数の補充・複数手順へ広げる。島を進めても、第一島の問題は難しくしない。

既存文書には「もうすぐ４歳向け」とあるが、３島の推奨年齢は定義されていない。そのため具体的な年齢は今回の確定仕様に追加せず、第一島が最もやさしいという順序を採用する。出生年月、星の数、正解率で入島を制限しない。推奨年齢を後から定めても、遊べる条件とは分ける。

第一島の中心は色・形・数・どうぶつの４分野だけ。数は１〜１０を順番に繰り返し、読みや計算を回答条件にしない。施設や管理画面を減らし、同時に複数のお願いを出さない。お手伝いを終えなくても、基本の知育を繰り返せる。第一島のお手伝いの数は最大３に収める。

第二島は、第二島の新しい遊びを一度に全部提示せず、見本合わせ、文字、収集の入口を分ける。第三島は、第二島で触れた内容を暮らしやおつかいに使う場所にする。３島の学習内容は累積で、前の島へ戻って復習できる。

## 英語の最初の体験

第二島では、見本の大文字と同じカードを選ぶ。最初は少数の文字を繰り返し、全２６文字を一度に出さない。絵を添えて、文字と身近なものを結び付けることはできるが、つづりの暗記や入力は求めない。

第三島では、果物・どうぶつ・色など、既存の絵を使える少数の英単語から始める。絵を見て単語を選ぶ問題と、単語を聞いて絵を選ぶ問題は別々に出し、初めから複数の条件を組み合わせない。誤答では減点せず、正しい絵・文字を示して再挑戦できる。

英語の発音は日本語音声で代用しない。今回の実装は、端末に利用できる英語音声があれば発音ボタンを使える。音声がない場合は無効表示し、絵と文字の見本で学べる。聞き取りだけの問題は出さない。追加録音・外部生成API・課金の利用はなし。既存の音声一覧・原本・未収録計画を保持する。英単語は果物・どうぶつ・色の７語で、最初の段階は４語。

## 今ある機能の扱い

変更前の第一島は、５分野のみつける遊び、数字の学校、虫・魚・貝・化石の収集、木ゆらし、畑、店、売却、図鑑、家具の配置を持っていた。第二島は `Forest` を入口にする港町で、森のお届けと港町のおつかいが同居していた。

今回、第二島は別の場面として「わくわくのしま」を新設した。既存の地形と木の素材を再利用し、学校・木ゆらし・ジャンプ・文字の学習を配置。既存の港町を第三島へ割り当て、別場面の「くらしのひろば」に店・畑・おうちを配置した。港町と暮らしの広場は第三島内で往復できる。追加場面は初めて訪問するときだけ準備する。

第二島は「しま」ボタンからいつでも選べる。第三島は既存の花のお届け完了条件を引き継ぐ。年齢・星・正解率で制限しない。第一島の船の案内は第二島へ進み、第三島は島選択から選ぶ。どの島からも第一島へ帰れる。

本人からオールリセットの許可も受領したが、今回の分離は保存の作り直しを必要としなかったため、リセットは実施していない。既存プロフィールと音声は維持した。新しい学習パネルの問題番号・挑戦段階はその場の練習で、閉じると終了する。英語の結果を従来のひらがな成績へ混ぜず、新しい成績保存や自動難化は追加していない。

星で難しさが変わる学校と、分野別の自動調整があるみつける遊びは別体系になっている。第一島には島ごとの上限を適用し、高い固定設定や既存の星があっても基本範囲を超えない。設定を消さず、後続島で使えるようにする。島ごとの問題を既存の調整記録へ追加する際は、問題条件が異なる記録を同じ成績として扱わない。
