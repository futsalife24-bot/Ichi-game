## 全島共通の作成基準

- 見本を見る、一緒に試す、自分で試すの３段階を用意する。前の島へ戻る復習と、得意な分野を先に試す機会を残す。
- 年齢・星・正答率・読み書きの完成を渡航条件にしない。第一島で10まで全部習得することも第二島への条件にしない。現行第三島の花のお届け条件は、学習試験と分けたお話の進行条件として扱う。
- 最初は一つの判断に絞る。数と色などを組み合わせる問題には、それぞれ単独で遊ぶ見本と復習を添える。
- 文字が読めない子も声・絵・実物・チェックリストで遊べる。英語音声を日本語音声で代用せず、声が使えない環境でも絵と見本で続けられる。
- 英語は第二島から少量ずつ。全26文字、つづり、書字を必須にしない。第三島では身近な単語、後の島では短い表現を繰り返して使う。
- 誤答では減点せず、見比べる見本や途中の手がかりを示す。正答を毎回同じ位置・色・大きさで当てられないようにする。
- 数える対象は一つずつ見える。重なり・木陰・装飾・別の収集物で数を曖昧にしない。同じ数の物を並べ替えた比較も用意する。
- 時間制限や暗記を中心にせず、途中でやめて再開できる。２手順以上は絵のチェックリストで段取りを支える。
- お届けは１件から始める。役割・相談・順番・生命を大切にすることは全島に織り込み、現実の親子の会話や遊びへつなぐ。ゲーム内のジャンプを身体運動の習得とは扱わない。
- 見た目は学ぶ対象を目立たせるために使う。色の問題で背景の配色に正解を埋め込まず、装飾物を回答物や収集物と誤認させない。

## 問題とおてつだいの記録様式

新規作成では、上のIDを出発点に同じ島番号のIDを追加する。１件ごとに次を記録する。

| 項目 | 記録する内容 |
| --- | --- |
| 学びと島 | 主に扱う力、数と文字の範囲、この島に置く理由 |
| 出し方 | 子ども向けの短い文、声、絵、見本、対象と選択肢 |
| 成立条件 | 一つの正答か複数の成立解か、誤答で見せる手がかり |
| 操作と段取り | タップ・移動・配置、手順数、中断と再開の地点 |
| お話 | 頼む相手、必要な理由、お礼。学習を先へ進む試験にしない |
| 素材 | パーツ台帳のID、背景、置ける数、当たり判定、触る対象の分離 |

## 島デザインの確認

島の入口・通常カメラ・回答する場所を第一〜第八島で比較する。名称と配色だけで区別せず、第一島の平らな小広場、第二島の丘と学校、第三島の水辺の建築、第四島の作業面、第五島の開いた屋台、第六島の観察区画、第七島の目印のある道、第八島の空いた中央広場という空間の違いを確認する。

回答物を隠す葉や屋根、操作を邪魔する装飾、歩行を止める当たり判定、画面外にある届け先を実ゲームで確かめる。Blenderの一覧レンダーだけで完成としない。初めは各島の問題１件とおてつだい１件が成立する素材から作り、背景の装飾は後に足す。
