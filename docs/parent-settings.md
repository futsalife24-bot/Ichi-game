# 保護者による難しさとヒント設定（2026-10-03）

## 範囲と承認

ブランチ codex/parent-settings、基点 54fd09f。ユーザーが「まず手動設定を作る」を選択。分野別固定・自動／手動ヒント・次の活動から反映を実装する。記録画面の表形式はユーザーが合格確認済み。任意監査は省略し、自己レビューと必要な検証で進める方針を継続。

## 動作

タイトル→記録を見る・保存→いまの子の遊びの設定。子どもの呼び名を見出しにし、色・形・数・言葉を表に並べる。設定対象は自由遊びの「みつける あそび」。学校・お手伝いは従来どおり。

難しさは「これまでどおり（星に連動）」または既存出題の段階へ固定。色4段階、形2段階、数4段階、ひらがな3段階。同じ出題内容を重複した段階として並べない。言葉の固定はひらがなに適用し、鳴き声の内容は変えない。段階を年齢・能力ランクとは呼ばない。未設定は既存の星連動を維持し、ユーザーが固定した分野だけを星から切り離す。

ヒントは分野ごとに「自動でも出す／押した時だけ」。どちらも島の活動中の💡ヒントボタンから要求できる。自動のタイミングは既存18秒を維持し、発達基準とは扱わない。お願いの聞き直しは別の操作のまま。手動ヒントも活動記録へ保存する。

活動開始時に難しさとヒント方式のスナップショットを取り、その一周を維持する。学校が参照する従来のlevelと、島のactivityLevelは分離した。新たな自動難化、出生年月による初期設定、保護者本人確認は今回加えない。

## 保存

プロフィール内のgame.playSettingsへ version:1 と domains を互換追加。各分野は level（nullは従来方式）と hints（auto/manual）を持つ。設定なしの旧データはそのまま読める。保存は既存のプロフィールストアを通し、控え・書出し・復旧の対象に含む。保存失敗時は画面の設定値をゲーム状態へ確定せず、元の状態へ戻す。将来版や不正値は初期化せず停止。
