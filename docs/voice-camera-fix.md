# 生成録音の復旧と俯瞰の調整（2026-10-16）

開発者モードの全開放入口で、開始ボタンを省略した際に音声の初期化も省略されていた。録音ファイルは843個とも残っていたが、再生器が未作成のため端末読み上げへ切り替わっていた。

最初のタップ・キー操作・クリックで音声を初期化し、その前の案内は待機する。待機中に停止、ミュート、別の案内があれば古い案内を再生しない。第一島への直接入場と一時データの全開放は維持する。既存の音声原本・一覧・MP3は変更せず、追加生成と課金はない。

全島の通常視点を俯角約16.4度から約25度へ変更。高さと距離を合わせて調整し、橋の手すりによる遮蔽回避を保持した。風車の遊び中も同じ角度のまま平行に移動する。

## 検証

- Node全382テスト成功。操作待ち・録音への復帰・古い案内の取消しを追加検証。
- 音声の必須検査と全843音声の完全性検査成功。
- 実形状による第三・第四・第七の橋の遮蔽、全島の主役と下部ボタンの間の身体位置を検査。
- Chromeの開発者モードで、操作前は音声待機・端末読み上げなし、最初の図鑑操作後は録音モードと音声再生器の稼働・再生終了を確認。
- 横向き相当の画面で第一・第六・第七・第八島を確認。風車演出の記録でも視線方向を保持。警告・エラー０。
- 実スマートフォンと人による聴感は未確認。別の場面でも声が変わる場合は追加調査する。
