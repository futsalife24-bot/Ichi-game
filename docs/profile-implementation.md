今回は子ども別保存・引き継ぎ・切替まで。分野別の観察、生まれた年月の入力、難易度判定、島、誕生日、時間制限は未実装。難易度は各プロフィール内の既存の星数方式が残る。元の設計案は次段階を含むため、本記録を実装範囲の正本とする。

## 動作

初回に保護者が絵と呼び名を選び、確認後に既存記録をその子へ引き継ぐ。名前は必須にせず「1ばん」などで利用できる。追加の子は持ち物・星・途中経過を引き継がず新規状態から開始。プロフィールの切替はタイトル画面から行う。複数の子がいる場合は起動時にも絵の選択を必須にする。

切替前に現在のゲームを保存し、プロフィール全体の選択先を保存してからページを読み直す。旧セッションの書込みは封鎖し、遅延処理が次の子に混ざることを防ぐ。Web Locksは従来どおり同一オリジン全体の排他制御として使用。

保護者向け追加入口は本人確認ではないことを表示する。認証方式が未決のため本人確認機能を装わない。プロフィールの削除・出生年月・外部送信は追加していない。

## 保存・復旧

新キー kirakira-island-profiles-v3 に schemaVersion:3、activeProfileId、profiles、legacyAssigned をひとまとめに保存。プロフィールは id、label、icon、game。gameは既存の全状態を含み、未知項目も保持する。

旧v1/v2は読むだけで書き換えない。引き継ぎ前に原文を v3-original へ保存・読み戻し確認し、新本体も読み戻して確認する。読み込みだけでは移行しない。v3がある場合は旧データから再移行しない。引き継ぎ元の変更、不一致の控え、破損、将来版では停止する。

更新前の全員分の本体を v3-previous、その前の復旧点を v3-retained-previous に保存。失敗後は同一セッションの書込みを拒否。復旧は全員分と選択中の子をまとめて戻すため、その影響を確認文で説明する。復旧前の本体も before-restore に残す。書き出しには全員分と旧v1/v2および控えを含む。

旧版へコードだけ戻すと、v3以降の進行を旧版は読めない。旧キーが残ることと、新進行を旧版へ戻せることは別。ファイルからの自動復元やプロフィール削除は未実装。サイトデータ削除は案内しない。
