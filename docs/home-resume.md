# ホームの振り返りからゲームへ戻る修正

2026-10-03、基点は公開main 7e3ac41c84a121b05075964fd770b31ec919cbc5。ブランチ codex/home-resume。

ユーザーのスマホ画面で、ホームを押すとタイトルへ戻る選択しかない問題を確認した。原因はmain.jsのホーム操作が、画面を出す前に活動を中断してプレイを終了していたこと。

ホーム操作では活動を終了せず一時停止し、「ゲームにもどる」「タイトルへ」を表示する。戻る時は場所・活動・同じ回の計測を維持する。画面表示中は島と活動を進めず、時間にも加算しない。タイトルへを選んだ時だけ従来の終了処理を行う。期限到達時の継続選択は維持し、通常のホームから戻る操作で期限を無効化しない。

保存形式の変更・データ削除・音声生成なし。誕生日の設計ブランチとは分離した。

対象テスト16件成功。実際のmain.jsから処理を実行し、終了処理を呼ばないこと、同じ回の時間を再開すること、通常の復帰で期限超過の継続フラグを立てないこと、画面中にフレーム処理が進まないことを確認した。main.js構文検査成功。実スマホでの修正版操作は未確認。
