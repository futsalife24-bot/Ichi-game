# 第二島の自然表現・制作資料

調査日：2026-10-07。本人の「第一島以上の描写・広さ、水の流れ、木と地面の質感を仕上げる」という指示に対応する。第一島の基準は `src/world.js` と `docs/first-island-visibility.md`、改修前の第二島は `src/forest.js`。以下の数量・配置・描画予算は制作上の提案で、自然科学の事実や端末での検証結果とは区別する。

## 素材を利用する場合の区別

- 今回の調査では画像・モデル・テクスチャをダウンロードしていない。参照したページの画像をそのままゲームへ貼らない。
- NPS/US Forest Serviceのページは観察・根拠として参照する。写真ごとの著作者や利用条件を確認していないため、配布素材とは扱わない。
- 上記3点のPoly Haven素材は各配布ページにCC0表示があり、[公式ライセンス](https://polyhaven.com/license)は素材の商用利用・改変・再配布を認めている。サイトの文章、ロゴ、見本レンダー等はCC0素材とは別の扱いなので転載しない。
- 採用した場合は素材名、作者、配布URL、CC0、取得日、元ファイルと加工ファイルのハッシュ、縮小・色調整内容を記録する。1K程度から試し、表示を比べて必要な部分だけ増やす。
- [Moss 01](https://polyhaven.com/a/moss_01)はCC0だが元モデル約24.6万三角形、[Rock Moss Set 01](https://polyhaven.com/a/rock_moss_set_01)は約6.3万三角形の表示がある。繰り返し配置するために原形をそのまま採用せず、低面数への整理か自作の参考にする。

## 広い島を成立させる配置案

主担当が地形・経路との整合を確認して採否を決める。旧活動の葉っぱ3枚とカエル、船、保存形式を維持したまま景観を広げられる。

1. **南の船着き場**：明るい入口。到着直後に川の方向と橋を見せる。船の周りは移動半径4以上の余白を確保する。
2. **中央の渓流と木橋**：川沿いに浅瀬・岩・草をまとめる。橋の両端は低い植生だけにし、端と道が途切れて見えないようにする。
3. **奥の大木と森の広場**：太い根、枝分かれ、樹皮が見える大木を目印にする。大木の手前を明るく開け、カエルと完成した飾りが樹冠の裏に隠れない位置にする。
4. **上流の小滝または段差のある瀬**：外周の景観に高低差を作る。岸沿いの小道から水が落ちる起点と着水部を見せる。高い場所へ実際に登れる設計にする場合は当たり判定と経路を先に確かめる。
5. **片側の木漏れ日の林と反対側の花の空地**：同じ木を円周に並べる代わりに、樹形・密度・地表で場所を区別する。奥の景色を見せる窓を林の間に残す。

最低の道幅は第一島の予約地と同等の中心線から左右1.8。主人公の手前に高木の樹冠が来る区間では、道幅だけでなく固定カメラからの見通しを確保する。島を拡大しても活動地点間は橋を含む連続した道で結び、道に沿って次の目印が見えるかを実画面で確認する。

## Blenderで作る細部と低負荷の目安

- 高木は最低2つの樹形と1本の目印になる大木を作る。幹の太さの変化、枝の付け根、根の接地、樹冠の重なりが近寄って分かる形にする。近景の大木を丁寧に作り、遠景へ同じ密度を要求しない。
- 大岩は形の異なる3種以上を作る。平らな接地面、割れ目、上面のコケ、川側の濡れた帯を持たせ、回転と大きさの変更でも同じ岩だと目立ちにくくする。
- 橋は床板の間隔、両端の接地、支柱、手すりを揃える。細い釘のようにゲーム画面で見えない部品を増やす前に、木目と板の幅・影を仕上げる。
- 共有の材質と繰り返し配置を使い、草・石・背景木は描画をまとめる。透過した葉カードを何層も重ねず、近景の輪郭を形状で表す。水は数枚の面で流れを表現し、全画面の反射処理を初期条件にしない。
- 初期の目安は景観追加分15万三角形以内、繰り返す木1本1,000〜3,000三角形、地表用の主要テクスチャ1K〜2K。固定値を品質の根拠とせず、実計測後に調整する。
- 同じChrome・同じ844×390の条件で第一島と第二島の描画回数・三角形・フレーム時間を記録する。第一島との差を残し、橋・大木の最も重い視点も測る。30fps未満の継続や操作遅延があれば、遠景や小物を先に整理する。実スマホ未検証なら合格扱いにしない。

## 見た目の受入確認

完成判断には、Blenderでの接写と実ゲームの通常カメラの両方を使う。Blenderだけの照明や高解像度レンダーではゲームの仕上がりを保証しない。

- 第一島・第二島を同じ昼・画面サイズ・通常カメラで並べ、第二島の方が地形も密度も少なく見えない。
- 船着き場・橋・大木の広場・上流の4地点で、地形、遠景、中景、足元の素材が重なって見える。
- 静止画でも川と地面を区別でき、動かすと上流から下流への方向が明確。短い動画で水面模様・泡が瞬間移動しないことを確認する。
- 木へ近寄ると樹皮、枝分かれ、根が見え、草地から土・落ち葉・湿った岸へ切り替わる様子が分かる。
- 667×375でも主人公、橋の入口、葉っぱ、カエル、帰り船が草木やUIで隠れない。収集からお礼・帰島まで一周でき、再訪で成果を保持する。

調査は主担当の依頼で分担した。モデルIDと推論設定は取得できず未確認。ブラウザーUI操作、コード変更、素材導入、公開はこの調査では実施していない。
