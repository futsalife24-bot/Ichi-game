## 保存物

- PNG８枚：内蔵の `image_gen.imagegen` で生成。最終選定版をこのフォルダへコピーした。
- [画像集PDF](../../../../output/pdf/eight-islands-concept-art-v1.pdf)：１島１ページの８ページ。原寸画像を切り取らず配置し、日本語の島名と守る要点を添えた。
- [３Ｄ制作基準](PRODUCTION.md)：地形・主役・配置・必要パーツ・見比べ方。後のBlender依頼で読む。
- [最終版の記録](catalog.json)：島設定、共通指示、個別指示、局所修正の指示、選定した生成ファイル名。
- [初回生成の指示](prompts.json)：生成を始める前に固定した８案。
- [視覚確認](REVIEW.md)：制作担当子１体が全画像を開いて確認。第二島の雪山を森と湖へ修正し、第三島の岸道を橋まで接続した。
- `manifest.json`：原寸・ハッシュ・Driveで確認できたファイルと共有先。
- [PDFの組み立て](build-gallery.py)：保存済みPNGを加工せずPDFへ配置する再生成用スクリプト。PythonのreportlabとWindowsのメイリオを使用する。

主担当が設計、生成、局所修正、統合、保管を担当。子１体が差別化・道の見え方・３Ｄで残す形を確認した。Chatによる独立監査ではない。使用した画像生成は内蔵ツールで、画像モデルの識別子と内部推論設定は取得不可。主担当・子の実行モデルIDと推論設定も未確認。
